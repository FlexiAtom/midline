# 中线 · midline

《中线》核心规则引擎的命令行实现。Rust，**零外部依赖**（`Cargo.lock` 里只有 `midline` 自己）。

**目前只有 CLI。** 这份代码是后续形态（TUI → 2D → 3D）的底座，画面层还没开始；规则文档里写的目标平台是
Android + Godot，本仓库交付的是它的**可执行规则内核**，以及一整套能对着文档复核的机检。规则规格文档
《中线》完整玩法方案（23 章）不随本仓库分发。

## 玩法一分钟版

- **类型**：卡牌对抗 + 棋盘策略 + 融合造牌。单局 3–6 分钟，完全离线。
- **棋盘**：横屏，中间是一条**中线**。敌方两排——后排 `E1–E4` 不可被攻击，前排 `E5–E8` 紧贴中线；
  我方一排 `P1–P4` 全部可攻击。手牌上限 8 张。
- **持业者是一根蜡烛**：正常燃烧不减短，只有伤害结算时才减短。烛尽，人亡。
- **业力**是唯一资源。开局业力为 0，固定发 1 张「开端」＋3 张牌堆牌（这 3 张不计入每回合抽牌次数），
  回合开始再自动抽 1 张 ⇒ 第一手 5 张。放开端让它每回合攒业力，还是献祭它换第一笔业力爆发，
  是每一局的第一个抉择。
- **献祭**回收卡牌换业力；卡牌在战斗中获取**随机技能**，再用**融合**把技能合并成自造牌。
  自造牌可以跨关继承，但**阵亡即永久消失**。
- **伤害回滚仅玩家拥有**：本回合已经打出的伤害可以拿来抵消敌方这一击，超额部分按我方攻击顺序反打回去
  （代价是这笔伤害被消耗掉，且下回合业力 −1）。
- **单机模式**：主线 60 关分 5 章、章末 Boss（炉主／雪爵／影长／炎与冰／终影），另有以日期为种子的每日挑战。

## 编译

```sh
cargo build --release     # 产物：target/release/midline
```

无外部依赖 ⇒ 不需要联网拉包。工具链下限由 `edition = "2024"` 决定（该 edition 自 Rust 1.85 起稳定）；
本仓库的实测环境是 1.97.1，1.85 上未实跑。

## 跑一把

```sh
./target/release/midline play        # 普通爬关（不落盘）
./target/release/midline mainline    # 主线 60 关，自动存档
./target/release/midline help        # 完整命令面
```

命令面（与 `help` 输出一致）：

| 命令 | 作用 |
|---|---|
| `play [--seed N] [--faction 1\|2\|3] [--difficulty X]` | 普通爬关，阵营三循环，不落盘 |
| `play --boss <id>` | 跳打某章末 Boss |
| `mainline [--seed N] [--faction …] [--difficulty X]` | 主线 60 关（5 章，章末 Boss），自动存档 |
| `mainline --resume [--save F]` | 从存档的「本关入口」续打；不给 `--resume` 则从第 1 关重开 |
| `boss <id> [--seed N]` | 单关跳打 Boss（`<id>` = 1–5，或 `luzhu`／`雪爵`… ） |
| `daily [--save F]` | 每日挑战（以日期为种子；打赢一关即记当天已做，不动主线进度） |
| `progress [--save F]` | 只读看当前存档；档读不懂则 `rc=2` |
| `progress recover [--save F]` | 把当前档改名留证 `.bad-N`，下次从空档开始 |
| `auto [N] [--difficulty X]` | AI 托管模拟 N 局（默认 1，不落盘） |
| `auto [N] --boss all\|<id>` | Boss 脚本冒烟：N 轮 × 5 个（或指定） |

`--faction` 1＝烬火教团／2＝霜誓守卫／3＝幽影议会。不给 `--seed`／`--faction` 时＝种子 7·烬火；
给了却读不懂会直接报错退出（`rc=2`），不会静默回退成别的值。

战斗内一行一条命令：`p <手牌idx> <P1-P4>` 放置｜`s <P1-P4>` 场上献祭｜`sh <idx>` 手牌献祭｜
`di`／`ds` 抽继承堆／开端堆｜`e` 结束回合｜`l` 日志｜`b` Boss 档案｜`q` 退出。
准备与关间结算阶段：`go`／`fuse <主> <副>`／`up <idx> power|thr|skill`／`drop <idx>`／`move <从> <到>`。

## 存档

只有 `mainline` 与 `daily` 会落盘。存档点＝**关隘入口**：败／平／弃三种退路都不动盘，下次续上的就是没过关的那一关。

落点优先级：`--save <文件>` ＞ `$MIDLINE_SAVE` ＞ `$XDG_DATA_HOME/midline/` ＞ `$HOME/.local/share/midline/`。

坏档一律 `exit 2` 拒载，**不会**被当成空档静默重开（免得你以为在续第 N 关、实际拿到第 1 关牌序）；
`progress recover` 会把坏档改名留证 `.bad-N` 而不是删掉。
